# SNSブレイク

SNSを開こうとした瞬間を、やりたいこと（読書など）の時間に変える iPhone Safari 向けWebアプリです。
HTML / CSS / JavaScript のみ。データは端末の localStorage に保存し、サーバーは使いません。

## 使い方の流れ

1. iPhoneのショートカットのオートメーションで、Instagram などを開いた瞬間に
   `https://ru8i2.github.io/sns-break/?from=instagram` を開く
2. 「ちょっと待った！」画面 → 「はじめる」でストップウォッチ開始
3. 1分以上で記録（1分未満なら「もう少しだけ続けてみる？」と聞くだけ）
4. 「それでも開く」を押すと元のアプリを開き、その回数も記録
5. ホームの「今週のレポート」で、今週奪った時間・回数を 9:16 のカードで表示

### `?from=` に使える値

| from | 表示名 | 開くURLスキーム |
| --- | --- | --- |
| `instagram` | Instagram | `instagram://app` |
| `x` / `twitter` | X | `twitter://` |
| `tiktok` | TikTok | `snssdk1233://` |
| `youtube` | YouTube | `youtube://` |
| `facebook` | Facebook | `fb://` |
| `threads` | Threads | `barcelona://` |
| `line` | LINE | `line://` |

上記以外は、`?from=xxx` → `xxx://` で開こうとします。
`?view=report` を付けると、レポート画面を直接開きます。

## iPhoneのショートカット設定

### なぜショートカットが2つ必要か

オートメーションは「Instagramが開かれた」ときに毎回動きます。
「それでも開く」から Instagram を開くと、またオートメーションが動いてこのアプリに戻ってしまいます。
そこで「それでも開く」のときは **通過用ショートカット（SNSパス）** を経由し、
その直後30秒はオートメーションが何もしないようにします。

### ① 通過用ショートカット「SNSパス」を作る

ショートカットApp →「ショートカット」タブ → 右上の「＋」

1. 名前を **SNSパス** にする（アプリの設定画面で変えた場合はその名前）
2. アクション「**テキスト**」を追加 → 中身に `pass` と入力
3. アクション「**ファイルを保存**」を追加
   - 「保存先を確認」：オフ
   - 保存先：`Shortcuts` フォルダ、サブパス：`sns-break-pass.txt`
   - 「上書き」：オン
4. アクション「**URLを開く**」を追加 → URL に変数「**ショートカットの入力**」を入れる
5. 画面下の「ⓘ（詳細）」→「**入力を受け取る**」をオンにし、種類は「テキスト」を含める
6. 一度だけ手動で実行しておく（`sns-break-pass.txt` が作られます。URLが空なのでエラーが出ても問題ありません）

### ② オートメーションを作る（アプリごとに1つ）

ショートカットApp →「オートメーション」タブ → 「＋」（または「新規オートメーション」）

1. 「**App**」を選ぶ → 「選択」から **Instagram** を選ぶ
2. 「**開いている**」にチェック、「**すぐに実行**」を選んで「次へ」
3. 「新規の空のオートメーション」を選び、以下のアクションを順に追加
   1. 「**ファイルを取得**」：`Shortcuts` フォルダの `sns-break-pass.txt`（「見つからない場合はエラー」はオフ）
   2. 「**ファイルの詳細を取得**」：詳細を「**修正日**」にする
   3. 「**日付間の時間を取得**」：「修正日」と「現在の日付」の間、単位は「**秒**」
   4. 「**if**」：「日付間の時間」が「**次より大きい**」`30`
   5. if の中に「**URLを開く**」：`https://ru8i2.github.io/sns-break/?from=instagram`
   6. 「otherwise（その他の場合）」の中は空のまま
4. 「完了」

X や TikTok にも使う場合は、②をアプリごとに作り、URL末尾を `?from=x` `?from=tiktok` などに変えます。

### うまく動かないとき

- 「それでも開く」で「ショートカットが見つかりません」と出る → ①の名前とアプリの「設定 → 通過用ショートカットの名前」を一致させる
- 「それでも開く」でまた戻ってくる → ②の if の数字（30秒）を少し大きくする
- ショートカット経由を使わない場合は、アプリの設定で「アプリを直接開く」を選べます（ただし上記の理由で戻ってきやすくなります）

## ホーム画面に追加する

Safari で開いて、共有ボタン →「ホーム画面に追加」。

> **注意**：iPhoneでは「ホーム画面に追加したアプリ」と「Safari」の保存データ（localStorage）が別々になります。
> オートメーションから開くのは Safari なので、記録は Safari 側にたまります。
> レポートを見るときは Safari で `https://ru8i2.github.io/sns-break/?view=report` を開く（ブックマークしておくと便利）か、
> ショートカットで「URLを開く」にこのURLを入れてホーム画面に置くと、同じデータを見られます。
